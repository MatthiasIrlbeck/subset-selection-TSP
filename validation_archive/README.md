# Historical validation evidence

This directory contains validation artifacts generated by earlier development milestones.
They are retained for reproducibility and historical comparison, but they are **not** evidence
for the current release unless a document explicitly says otherwise.

Each version directory preserves the original result files, manifests, logs, and local notes.
Current release validation lives in `validation_runs/current/` and is required by CI to match
the project version and current result schema exactly.
