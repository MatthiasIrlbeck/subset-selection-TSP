# Validation archive: 0.8.7

These files were generated by solver version 0.8.7, primarily with result schema 13. They are
historical evidence only and are preserved verbatim for auditability.

Notable environment-dependent records include an earlier real-LKH run and local
original-prototype comparisons. Their presence does not imply that LKH, Concorde, or the
prototype were available during validation of 2.0.0.

The original validation tree is under `validation_runs/`; the former top-level local note is
`VALIDATION_LOCAL.md`; and the external comparison artifacts are under
`external_validation/`.
