# subset-selection-TSP 2.0.0

Version 2.0.0 replaces the original public prototype with the audited C++17 library and
command-line solver developed in the repository's hardened branch.

## Highlights

- Correct periodic geometry, exact KNN construction, immutable prepared instances, strict
  public validation, and mandatory solution postconditions.
- A substantially faster subset solver with staged restart allocation, batched exact
  exchange neighborhoods, adaptive ruin/recreate, membership ejection chains, and
  held-out search-policy presets.
- A scalable full-TSP restart controller, optional exact cardinality-`k` subset solving for
  `N <= 18`, and conditional fixed-subset lower-bound diagnostics.
- Reproducible campaign identities, fail-closed manifests and resume logic, block-bootstrap
  analysis, multifidelity correction, cross-fitted control variates, and complete
  end-to-end timing.
- Strict schema-16 JSON, schema migration tools, durable atomic output, release-archive
  source identity, pinned CI actions, verified oracle inputs, SPDX SBOM generation, and
  SLSA/in-toto provenance.

## Compatibility and migration

The historical public `v1.0` repository contained the prototype solver. Version 2.0.0 is a
major release because the source layout, public API, option validation, and result schema
have all changed.

Native results use schema 16. Historical schema-13 documents can be migrated with:

```bash
python3 scripts/migrate_schema13_to14.py old.json --output old.v14.json
python3 scripts/migrate_schema14_to15.py old.v14.json --output old.v15.json
python3 scripts/migrate_schema15_to16.py old.v15.json --output old.v16.json
```

The default `legacy-balanced` search policy preserves the validated pre-preset controller.
The evidence-backed `heldout-balanced` and `heldout-quality` policies are opt-in.

## Scope of guarantees

The production solver is heuristic. Its reported tour lengths are upper bounds on the
unknown optimum. The two-NN and Held--Karp diagnostics are lower bounds only for the tour
ordering on the subset found by the heuristic; they are not global lower bounds for subset
selection. Exact subset-and-cycle certification is available only for supported small
instances when explicitly enabled.

## Validation

Release artifacts are generated from a signed annotated tag. The release workflow builds
and tests both the Git checkout and the extracted source archive, checks generated option
surfaces, validates bundled current evidence, creates deterministic ZIP and tar archives,
generates an SPDX 2.3 SBOM and an in-toto/SLSA provenance statement, and publishes
GitHub OIDC-backed attestations.
